# 多用户角色控制台平台

这是一个前端实现的多用户桌面控制台系统，支持多个用户角色登录，展示各自定制化的控制台视图。平台提供模块化侧边栏、亮暗主题切换、消息中心、多标签页内容区域，并支持用户界面配置的本地持久化。

---

## 🌟 项目亮点

- **多角色支持**：平台管理员、项目经理、系统架构师、仿真工程师、建模工程师。
- **模块配置**：根据角色加载不同的功能模块，支持模块显隐勾选。
- **标签页视图**：内置多标签页（总览 / 日常 / 统计 / 设置）用于分类展示内容。
- **消息中心**：各角色拥有独立消息通知列表，可手动查看与关闭。
- **亮/暗主题切换**：用户可自由切换界面风格，系统自动记忆上次设置。
- **布局本地保存**：用户可对显示模块自定义配置，切换角色时自动恢复。
